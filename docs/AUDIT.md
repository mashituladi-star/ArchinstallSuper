# Аудит и исправления

Дата аудита: ноябрь 2026. Версия: 0.11.0. Ветка: `main`.

Аудит 0.10.0 выполнялся в ветке `feature/v1-audit-modernization`; она влита в
`main` fast-forward вместе с PR #1. Версия 0.11.0 добавляет современный
полноэкранный интерфейс.

## Кратко

Проект начинался как монолитный `install.sh` с несколькими критичными ошибками:
незахваченные значения `dialog`, отсутствие `rootflags=subvol=@` для Btrfs,
хрупкий разбор дисков, отсутствие предполётной проверки пакетов и очистки после
сбоя. В этой ветке установщик разделён на модули, критичные ошибки исправлены,
добавлены unit-тесты, статические проверки и интеграционный QEMU/UEFI-скрипт.

## Что добавлено

- Модульная структура `lib/*.sh` (13 модулей).
- CLI: `--check`, `--dry-run`, `--plain`, `--debug`, `--log`, `--version`,
  `--help`.
- GPT + EFI 1 GiB + корень; ext4/Btrfs/XFS.
- Btrfs-подтомы `@`, `@home`, `@var_log`, `@snapshots`.
- LUKS2 с argon2id и безопасной передачей пароля.
- systemd-boot, `loader.conf`, загрузочная запись, микрокод, `mkinitcpio`.
- Проверка fstab, загрузочной записи, ядра, initramfs, пользователя,
  NetworkManager.
- Выбор ядра, профиля, окружения, zram, Wi-Fi.
- Плагины-хуки.
- 13 шагов тестов, включая поддельный `pacman`, safety-проверки диска,
  проверки recovery и QEMU/UEFI-скрипт.

## Обновление 0.11.0 — интерфейс

- Добавлен `lib/tui.py` — полноэкранный TUI на Python/curses: окно по центру,
  заголовок, боковая панель этапов, меню, ввод с курсором, маскировка пароля,
  подтверждения, сообщения, текст, выполнение команд и прогресс.
- Добавлен экран запуска (splash) с выбором «Начать установку / Выход».
- Интерфейс открывается сразу: `AS_UI_EARLY` и `core_silence_console` убирают
  консольный вывод до появления окна; диагностика идёт в журнал.
- `dialog` и `plain` сохранены как резервные бэкенды; выбор автоматический.
- Ошибки `die` и финальное сообщение после сбоя показываются в окне.
- Добавлены PTY-тесты `tests/unit/tui-test.sh`; полный набор — 14 шагов.
- Добавлена документация `docs/UI.md`.

## Остающиеся риски и ограничения

### Не проверено в реальном UEFI

В среде аудита не было `qemu-system-x86_64`, OVMF, KVM и root-доступа, поэтому
реальная установка и загрузка не выполнялись. Добавлен
`tests/integration/qemu-uefi.sh`, но его нужно запустить на машине с QEMU/OVMF.
До этого установщик нельзя считать проверенным на реальном железе.

### Secure Boot

systemd-boot не подписывается, ключи не заводятся. При включённом Secure Boot
система может не загрузиться. Это явное ограничение, а не ошибка.

### Нет неинтерактивного режима

Нельзя автоматизировать установку конфигом. Это осознанно: неинтерактивный
режим — деструктивная возможность, требующая отдельного ревью. Поэтому
QEMU-тест ручной.

### Нет swap и ручной разметки

Отдельный swap-раздел/файл не создаётся; доступен только zram. Разметка только
«весь диск», без сохранения других ОС.

### Проприетарные драйверы

NVIDIA и другие проприетарные драйверы автоматически не ставятся. Для
графических профилей устанавливается `mesa`.

### LUKS2

Шифруется только корень; `/boot` остаётся открытым. Нет TPM/FIDO2/detached
header. Параметры argon2id не настраиваются под объём RAM.

### Сеть и зеркала

Нет автоматического ранжирования зеркал. `pacman -Sy` выполняется в live-среде
(это нормально для установщика, но не является полным обновлением системы).

### Плагины

Плагины — доверенный локальный код с полными правами root. Автоматической
загрузки плагинов нет.

### Публикация

PR #1 смержен, `feature/v1-audit-modernization` влита в `main`, остальные
ветки удалены. Для отправки новых коммитов нужны свежие GitHub-учётные
данные: токен, использованный ранее, считается скомпрометированным.

### TUI проверен не на реальном ISO

Полноэкранный интерфейс проверен в PTY-тестах и при запуске установщика в
обычном терминале. Проверка на официальном Arch ISO, в QEMU/UEFI и на
реальном железе остаётся обязательной.

## Следующие шаги

1. Запустить `tests/integration/qemu-uefi.sh` на машине с QEMU/OVMF/KVM.
2. Проверить сценарии: ext4, Btrfs, XFS, LUKS2+Btrfs, `linux-lts`,
   `linux-hardened`, zram, Wi-Fi.
3. Проверить загрузку после перезагрузки и `bootctl status`.
4. Проверить TUI на официальном ISO: UTF-8, `TERM=linux`, маленький экран,
   изменение размера терминала, работа на реальной клавиатуре.
5. Добавить опциональный неинтерактивный конфиг после отдельного ревью.
6. Рассмотреть подпись systemd-boot и LUKS2 с TPM2/FIDO2.
