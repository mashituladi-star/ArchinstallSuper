# Интерфейс

## Почему TUI, а не GUI

Официальный live-ISO Arch Linux не содержит X11/Wayland и графического
стека. Настоящее графическое окно потребовало бы скачать и поднять сотни
мегабайт драйверов и toolkit до начала установки, зависело бы от GPU/VM и
могло бы не запуститься именно там, где установщик нужнее всего.

Поэтому используется полноэкранный TUI на Python/curses — максимально
современный вид, который работает на официальном ISO, в UEFI-виртуалках и на
реальном железе без дополнительных зависимостей.

## Как выглядит

При запуске сразу открывается окно установщика:

- тёмный фон и окно по центру терминала;
- заголовок с названием, версией и меткой UEFI;
- боковая панель этапов: текущий этап выделен, пройденные отмечены `✓`;
- содержимое экрана: меню, поле ввода, подтверждение, сообщение, текст или
  прогресс;
- нижняя строка подсказок по управлению.

Экран запуска предлагает «Начать установку» или «Выход». Перед установкой
показывается итоговый план и запрашиваются явные подтверждения (`ERASE ...`,
`INSTALL`).

## Управление

| Клавиши | Действие |
| --- | --- |
| `↑` / `↓`, `j` / `k` | перемещение по меню и тексту |
| `PageUp` / `PageDown` | прокрутка на страницу |
| `Home` / `End` | начало / конец списка |
| `Enter` | подтвердить выбор |
| `Esc`, `q` | отмена / закрыть экран |
| `←` / `→`, `h` / `l`, `Tab` | выбор кнопки в подтверждении |
| `y` / `n` (и `д` / `н`) | быстрый ответ |
| `Ctrl-U` | очистить поле ввода |
| `Ctrl-W` | удалить слово |
| `Backspace` / `Delete` | удалить символ |

Пароль отображается точками. Значение возвращается установщику, но не
рисуется на экране и не пишется в журнал.

## Бэкенды

`ui_init` выбирает бэкенд в таком порядке:

1. **tui** — если есть `python3` с модулем `curses` и терминал;
2. **dialog** — если установлен `dialog` и есть терминал;
3. **plain** — во всех остальных случаях, а также при `--plain`.

Принудительно текстовый режим включается флагом `--plain`. Он нужен для
отладки, CI и терминалов без полноэкранной поддержки.

## Совместимость терминала

- UTF-8 и 256 цветов используются, если доступны.
- При `TERM=linux`, отсутствии UTF-8 или `AS_UI_ASCII=1` включается
  ASCII-отрисовка рамок и иконок.
- При маленьком окне интерфейс уменьшается, длинные строки обрезаются, а
  списки и текст прокручиваются.
- При изменении размера терминала экран перерисовывается.

## Архитектура

TUI-помощник `lib/tui.py` запускается на каждый экран отдельным процессом.
Это делает интерфейс устойчивым: падение одного экрана не ломает терминал и
не оставляет curses в неопределённом состоянии.

Потоки данных:

```text
fd 1  экран терминала (curses)
fd 3  результат экрана для командной подстановки Bash
fd 4  исходный терминал (используется диспетчером ui.sh)
fd 5  живой вывод команды на экране program/gauge
```

- `lib/ui.sh` — единая точка входа: `ui_menu`, `ui_input`, `ui_password`,
  `ui_confirm`, `ui_msg`, `ui_error`, `ui_show_text`, `ui_run_logged`.
- Значения никогда не пишутся в журнал: журнал получает только диагностику.
- `AS_UI_CHILD=1` выставляется для команд, запущенных через `ui_run_logged`,
  чтобы их `die` не открывал вложенный экран. Ошибку показывает родитель.
- `AS_UI_STEPS` и `AS_UI_STEP_INDEX` передают боковой панели список этапов и
  текущую позицию.

## Тишина консоли

До появления окна установщик не должен показывать shell-вывод. Для этого:

- `install.sh` до `core_init` проверяет, что доступен полноэкранный режим, и
  выставляет `AS_UI_EARLY=1`;
- `core_init` в этом режиме направляет stdout/stderr сразу в журнал, а не
  через `tee` на терминал;
- `core_silence_console` окончательно убирает вывод из терминала после
  инициализации UI.

Диагностика остаётся в `/var/log/archinstallsuper.log` (права `0600`).

## Тесты

`tests/unit/tui-test.sh` запускает `tests/lib/tui_pty.py` в настоящем PTY и
проверяет:

- возврат выбранного значения через fd 3;
- отрисовку заголовка и боковой панели этапов;
- отмену по `Esc`;
- ввод текста и возврат значения;
- маскировку пароля (значение не появляется на экране);
- ответы `y`/`n` в подтверждениях;
- закрытие сообщения по `Enter`;
- показ вывода команды на экране выполнения;
- splash и возврат `install`;
- ASCII-режим и `TERM=linux`.

## Ограничения

- Это не графическое окружение: мышь, шрифты и произвольные цвета недоступны.
- Нет установки из файла конфигурации и полностью неинтерактивного режима:
  установщик намеренно требует явных подтверждений перед стиранием диска.
- Поведение curses зависит от терминала. Для нестандартных терминалов
  предусмотрен `--plain`.
