# ArchinstallSuper

Самостоятельный UEFI-установщик Arch Linux из официального ISO. Проект не вызывает archinstall. В интерактивном режиме доступен полноэкранный TUI на базе dialog (ncurses) с текстовым резервным режимом.

## Запуск

1. Запиши официальный ISO с https://archlinux.org/download/ на USB.
2. Загрузи компьютер именно в UEFI-режиме (Legacy/CSM не поддерживается).
3. Подключи интернет, затем выполни:

```bash
pacman -Sy --needed git
git clone https://github.com/mashituladi-star/ArchinstallSuper.git
cd ArchinstallSuper
bash install.sh --check   # предварительная проверка UEFI и интернета
bash install.sh          # запуск мастера
```

## Режимы

- Минимальная: консоль, base, Linux, firmware, NetworkManager, sudo, nano.
- Базовая: GNOME, GDM, PipeWire, Firefox и базовые инструменты.
- Полная: GNOME, LibreOffice, VLC, GIMP, Flatpak и инструменты разработки.
- Кастомная: консоль или GNOME/KDE/XFCE/Cinnamon, дополнительные пакеты.

## Интерфейс

При наличии dialog запускается полноэкранный мастер: выбор профиля, диска, системных параметров, паролей и финальное подтверждение. Во время установки пакетов открывается отдельное окно журнала pacstrap. Перед настройкой системы можно выбрать ext4 или Btrfs с отдельными подтомами для корня, домашнего каталога, журналов и снимков. Также доступна опциональная настройка zram (сжатый swap в оперативной памяти). Выбор графического окружения в кастомном профиле выполняется через меню dialog. Если dialog отсутствует, установщик пытается установить его из официальных репозиториев Arch; при неудаче остаётся текстовый режим. Интерфейс не требует графической среды и работает прямо в терминале Live ISO.

## Реализация

Установщик самостоятельно выполняет UEFI-проверку, выбор диска, GPT-разметку, форматирование EFI FAT32 и root ext4/Btrfs, установку пакетов, генерацию fstab, настройку локали, времени, пользователя, NetworkManager и systemd-boot.

Используются низкоуровневые штатные инструменты Arch: pacstrap, genfstab, arch-chroot, sgdisk, mkfs, mount, bootctl. Это не archinstall — его пакет и интерфейс не используются.

## ВАЖНО: ранний прототип

Перед разметкой проверяется размер диска (минимум 24 GiB), а также выполняется попытка защитить носитель, с которого загружена live-система. Проверяются доступность необходимых команд, локаль и раскладка. Текущий прототип автоматически стирает выбранный диск после двух подтверждений. Во время pacstrap выводится потоковый журнал, а не фиктивный процент выполнения. Все данные на нём будут уничтожены. Пока нет ручной разметки, шифрования диска и Secure Boot и механизма восстановления после отключения питания. Перед использованием на реальном ПК обязательны тесты в виртуальной машине со снимком диска.

Поддерживается только x86_64 UEFI. Для первого запуска требуется интернет.

## Проверка качества

В репозитории настроен GitHub Actions workflow `Installer quality`: при push и pull request он проверяет синтаксис Bash, выполняет статические проверки критичных защитных условий и запускает ShellCheck.

Локальная проверка:

```bash
bash -n install.sh
bash tests/static-checks.sh
shellcheck --severity=warning install.sh tests/static-checks.sh
```

Перед установкой можно выполнить безопасную предварительную проверку (она не размечает диски и не устанавливает систему):

```bash
bash install.sh --check
```
