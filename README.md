# ArchinstallSuper

Самостоятельный UEFI-установщик Arch Linux из официального ISO. Проект не вызывает archinstall. В интерактивном режиме доступен полноэкранный TUI на базе dialog (ncurses) с текстовым резервным режимом.

## Запуск

1. Запиши официальный ISO с https://archlinux.org/download/ на USB.
2. Загрузи компьютер именно в UEFI-режиме (Legacy/CSM не поддерживается).
3. Подключи интернет, затем выполни:

```bash
pacman -Sy --needed git
git clone https://github.com/mashituladi-star/ArchinstallSuper.git
cd ArchinstallSuper
bash install.sh
```

## Режимы

- Минимальная: консоль, base, Linux, firmware, NetworkManager, sudo, nano.
- Базовая: GNOME, GDM, PipeWire, Firefox и базовые инструменты.
- Полная: GNOME, LibreOffice, VLC, GIMP, Flatpak и инструменты разработки.
- Кастомная: консоль или GNOME/KDE/XFCE/Cinnamon, дополнительные пакеты.

## Интерфейс\n\nПри наличии dialog запускается полноэкранный мастер: выбор профиля, диска, системных параметров, паролей и финальное подтверждение. Если dialog отсутствует, установщик пытается установить его из официальных репозиториев Arch; при неудаче остаётся текстовый режим. Интерфейс не требует графической среды и работает прямо в терминале Live ISO.\n\n## Реализация

Установщик самостоятельно выполняет UEFI-проверку, выбор диска, GPT-разметку, форматирование EFI FAT32 и root ext4, установку пакетов, генерацию fstab, настройку локали, времени, пользователя, NetworkManager и systemd-boot.

Используются низкоуровневые штатные инструменты Arch: pacstrap, genfstab, arch-chroot, sgdisk, mkfs, mount, bootctl. Это не archinstall — его пакет и интерфейс не используются.

## ВАЖНО: ранний прототип

Перед разметкой проверяется размер диска (минимум 24 GiB), а также выполняется попытка защитить носитель, с которого загружена live-система. Проверяются доступность необходимых команд, локаль и раскладка. Текущий прототип автоматически стирает выбранный диск после двух подтверждений. Все данные на нём будут уничтожены. Пока нет ручной разметки, шифрования, Btrfs, swap/zram, Secure Boot и механизма восстановления после отключения питания. Перед использованием на реальном ПК обязательны тесты в виртуальной машине со снимком диска.

Поддерживается только x86_64 UEFI. Для первого запуска требуется интернет.
