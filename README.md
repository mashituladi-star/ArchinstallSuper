# ArchinstallSuper

Русскоязычный установщик-помощник для Arch Linux. Он запускается **после загрузки с официального Arch Linux ISO**, подключается к сети, предлагает профиль установки и передаёт конфигурацию официальному интерактивному `archinstall`.

ArchinstallSuper не является отдельным дистрибутивом и не требует пересборки ISO.

## Запуск с официальной флешки

1. Скачай официальный ISO с [archlinux.org/download](https://archlinux.org/download/) и запиши его на USB.
2. Загрузи компьютер с флешки.
3. Подключись к интернету. Для Wi-Fi открой `iwctl`:
   ```text
   device list
   station wlan0 scan
   station wlan0 get-networks
   station wlan0 connect "ИМЯ_СЕТИ"
   exit
   ```
   Замени `wlan0` на имя своего Wi-Fi-интерфейса.
4. Запусти установщик:
   ```bash
   bash <(curl -fsSL https://raw.githubusercontent.com/mashituladi-star/ArchinstallSuper/main/install.sh)
   ```

Альтернативно можно скачать файл, просмотреть его и запустить вручную:
```bash
curl -fLO https://raw.githubusercontent.com/mashituladi-star/ArchinstallSuper/main/install.sh
less install.sh
bash install.sh
```

## Четыре режима установки

### 1. Минимальная

Для тех, кто хочет самостоятельно собирать систему после установки.

- Без графического окружения и дисплейного менеджера.
- Минимум дополнительных пакетов.
- NetworkManager для подключения к сети после первого запуска.
- После загрузки пользователь попадает в обычную консоль и сам решает, что устанавливать дальше.

### 2. Базовая

Готовая повседневная система с GNOME.

- GNOME и PipeWire.
- Firefox.
- Nano, Git и Fastfetch.
- GNOME выбран заранее; остальные настройки остаются доступными в archinstall.

### 3. Полная

Более насыщенная рабочая станция на базе GNOME.

- Всё из базового режима.
- LibreOffice, VLC, GIMP и GNOME Tweaks.
- Flatpak.
- Инструменты разработки: Git, base-devel, Python и pip.
- Дополнительные системные утилиты: btop, htop, curl, wget и архиваторы.

### 4. Кастомная

Позволяет собрать установку под себя.

- Рабочее окружение: GNOME (вариант по умолчанию), KDE Plasma, XFCE, Cinnamon или установка без графики.
- По желанию — набор системных утилит.
- По желанию — инструменты разработчика.
- По желанию — программы для повседневной работы.
- Можно указать дополнительные имена пакетов через пробел или запятую.

## Что остаётся под контролем пользователя

После выбора режима запускается **официальный интерактивный archinstall**. ArchinstallSuper предварительно заполняет профиль рабочего окружения и список пакетов, но не выбирает за пользователя диск и не выполняет разметку.

Пользователь самостоятельно проверяет и подтверждает:
- диск, разделы, файловые системы и форматирование;
- загрузчик;
- имя компьютера, пользователя и пароли;
- язык, часовой пояс и остальные параметры.

В конфигурацию намеренно не записывается `disk_config`: установщик не получает от ArchinstallSuper готовой команды на стирание или разметку конкретного диска. Перед подтверждением внимательно проверь модель и размер диска, а также наличие резервной копии нужных данных.

Перезагрузка автоматически не выполняется.

## Что проверяет ArchinstallSuper

- Запуск от root в live-среде официального Arch Linux ISO x86_64.
- Наличие интернет-соединения и доступность DNS.
- Возможность подключиться к Wi-Fi через iwctl.
- Системное время.
- Наличие официального archinstall и Python.
- Валидность сгенерированного JSON перед передачей его установщику.

Конфигурация сохраняется во временный файл `/tmp/archinstallsuper-config.json`. В ней нет паролей или учётных данных.

## Проверка проекта

Локальная проверка:
```bash

python3 tests/profile-config-check.py
shellcheck --severity=warning install.sh
```

GitHub Actions автоматически выполняет проверку Bash, JSON-профилей и ShellCheck при каждом push и pull request.
