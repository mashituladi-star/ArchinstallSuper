# ArchinstallSuper

Русскоязычный запускатель установки Arch Linux из официального Arch ISO.

> Проект запускается **из уже загруженной live-системы официального Arch Linux ISO**. Он проверяет окружение и сеть, помогает подключиться к Wi-Fi и передаёт управление официальному `archinstall`. Разметка и форматирование дисков остаются под явным контролем пользователя.

## Текущий статус

Начальная версия проекта. Это безопасная оболочка над официальным установщиком Arch Linux. GNOME выбран как профиль рабочего стола по умолчанию; его можно отключить, чтобы выбрать окружение вручную. Настройки дисков, пользователя, сети и другие параметры пока остаются в интерактивном archinstall.

## Как запустить

1. Скачай официальный ISO с [archlinux.org/download](https://archlinux.org/download/) и запиши его на USB.
2. Загрузи компьютер с флешки.
3. Подключись к интернету. Для Wi-Fi в live-системе можно открыть:
   ```bash
   iwctl
   ```
   Внутри `iwctl` выполни:
   ```text
   device list
   station wlan0 scan
   station wlan0 get-networks
   station wlan0 connect "ИМЯ_СЕТИ"
   exit
   ```
   Замени `wlan0` на имя своего Wi-Fi-интерфейса.
4. Запусти ArchinstallSuper одной командой:
   ```bash
   bash <(curl -fsSL https://raw.githubusercontent.com/mashituladi-star/ArchinstallSuper/main/install.sh)
   ```
   Альтернативно, скачай файл и проверь его перед запуском:
   ```bash
   curl -fLO https://raw.githubusercontent.com/mashituladi-star/ArchinstallSuper/main/install.sh
   less install.sh
   bash install.sh
   ```

## Что делает запускатель

- Проверяет, что запущен именно live-образ Arch Linux и есть права root.
- Проверяет доступ к сети и DNS до начала установки.
- При отсутствии соединения предлагает открыть `iwctl` и повторить проверку.
- Проверяет системное время.
- Проверяет наличие официального `archinstall`.
- По отдельному согласию может обновить пакеты live-системы и `archinstall`.
- Предлагает GNOME как окружение по умолчанию (можно отключить и выбрать вручную).\n- Передаёт профиль GNOME официальному `archinstall` через локальный JSON-файл.\n- Запускает официальный интерактивный установщик командой `archinstall`.
- Не выбирает диск, не форматирует разделы, не задаёт пароль и не перезагружает компьютер автоматически.

## Безопасность

Установка Arch Linux может уничтожить данные на выбранном диске. Перед подтверждением разметки в `archinstall` внимательно проверь модель и размер диска, резервные копии и выбранный способ разметки. Не выбирай автоматическое стирание диска, если не уверен, что на нём нет нужных данных.

Скрипт не содержит встроенных паролей, не отправляет настройки сети на сторонние серверы и не выполняет удалённый код, кроме самого файла запуска, который пользователь явно запросил у GitHub по HTTPS.

## Проверка скрипта

На обычном Linux можно проверить синтаксис:
```bash
bash -n install.sh
```

Если установлен ShellCheck:
```bash
shellcheck install.sh
```
