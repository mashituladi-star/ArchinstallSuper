# ArchinstallSuper

Самостоятельный установщик Arch Linux для **x86_64 UEFI**. Проект не использует
пакет `archinstall` и не вызывает его: вся логика установки реализована на
штатных инструментах Arch Linux (`pacstrap`, `pacman`, `sgdisk`, `mkfs`,
`mount`, `genfstab`, `arch-chroot`, `bootctl`, `mkinitcpio`, `cryptsetup`).

Установщик рассчитан на запуск из официального live-ISO Arch Linux. Создавать
собственный ISO не нужно.

> **Статус:** версия 0.11.0, ранняя, но уже проверяемая. Перед установкой на
> реальный компьютер обязательно прогони установку в UEFI-виртуальной машине
> (см. [tests/integration/README.md](tests/integration/README.md)). Установщик
> стирает весь выбранный диск.

## Возможности

- UEFI/GPT, только x86_64. Legacy BIOS/CSM и MBR не поддерживаются.
- Современный полноэкранный TUI на Python/curses: окно по центру, боковая
  панель этапов, акцентные цвета, поля ввода с курсором, экраны прогресса.
  Интерфейс открывается сразу, без консольного текста перед ним. Резервные
  режимы: классический `dialog` и текстовый `--plain`.
- Файловые системы: **ext4**, **Btrfs** (подтомы `@`, `@home`, `@var_log`,
  `@snapshots`, сжатие zstd) и **XFS**.
- Опциональное шифрование корня **LUKS2** (argon2id, aes-xts-plain64).
- Ядра: `linux`, `linux-lts`, `linux-zen`, `linux-hardened`.
- Загрузчик: **systemd-boot** с явной загрузочной записью и проверкой
  `rootflags=subvol=@` для Btrfs и `cryptdevice=UUID=...` для LUKS2.
- Профили: минимальный, базовый (GNOME), полный, кастомный
  (GNOME/KDE/XFCE/Cinnamon или консоль).
- Определение оборудования: CPU, RAM, материнская плата, GPU, сеть, Secure Boot,
  микрокод Intel/AMD; предупреждение о нехватке памяти.
- Настройка live-сети, включая Wi-Fi через `iwctl`.
- Пользователь и root-политика (пароль или заблокированный root + sudo).
- Локаль UTF-8, часовой пояс, раскладка, hostname, `/etc/hosts`, sudoers.
- Включение NetworkManager, systemd-timesyncd, fstrim.timer и display manager.
- Опциональный **zram** (`zram-generator`).
- Предварительная проверка пакетов и оценка занимаемого места **до** разметки.
- Проверка fstab и результата установки после `pacstrap`.
- Блокировка от параллельного запуска, обработка сигналов, безопасное
  размонтирование и закрытие LUKS при ошибке.
- Локальные плагины-хуки (`plugins/*.sh`, только доверенный код).

## Требования

- Официальный live-ISO Arch Linux, загруженный в UEFI-режиме.
- Интернет в live-среде (проводной или Wi-Fi).
- Диск не меньше 24 GiB; весь диск будет очищен.
- Запуск от root (в live-ISO это обычный пользователь).

## Быстрый старт

```bash
pacman -Sy --needed git
git clone https://github.com/mashituladi-star/ArchinstallSuper.git
cd ArchinstallSuper

bash install.sh --check   # UEFI, live-среда, оборудование, интернет
bash install.sh           # интерактивный мастер
```

Перед разметкой установщик показывает итоговый план и просит два явных
подтверждения:

1. ввести `ERASE /dev/...` при выборе диска;
2. ввести `INSTALL` перед началом установки.

## Параметры командной строки

```text
bash install.sh              интерактивная установка
bash install.sh --check      только проверка UEFI, live-среды и сети
bash install.sh --dry-run    собрать настройки и показать план без изменений
bash install.sh --plain      не использовать dialog
bash install.sh --debug      подробный отладочный вывод
bash install.sh --log FILE   писать журнал в FILE
bash install.sh --version
bash install.sh --help
```

`--dry-run` всё равно выполняет интерактивный опрос и проверку пакетов, но не
размечает диск и не устанавливает систему.

## Интерфейс

При запуске на терминале сразу открывается полноэкранное окно установщика:
тёмный фон, заголовок с версией, боковая панель этапов и строка подсказок.
Консольный вывод и журналирование при этом уходят в
`/var/log/archinstallsuper.log` и не мешают окну.

```text
╭──────────────────────────────────────────────────────────╮
│ ● ● ●   ArchinstallSuper        v0.11.0 · UEFI           │
│──────────────────────────────────────────────────────────│
│  STEPS    │ System profile                               │
│  ✓ Network│ Choose the software set to install.          │
│  ✓ Hardware│ › Minimal          console                  │
│  ● Profile│   Basic             GNOME                    │
│  ○ Kernel │   Full              GNOME + applications     │
│  ○ Filesystem                                            │
│  ...      │                                              │
│──────────────────────────────────────────────────────────│
│ ↑/↓ select   Enter confirm   Esc cancel                  │
╰──────────────────────────────────────────────────────────╯
```

- `↑`/`↓` или `j`/`k` — перемещение, `Enter` — выбор, `Esc` — отмена.
- `y`/`n` — быстрый ответ в подтверждениях, `←`/`→` — выбор кнопки.
- Пароли отображаются точками и никогда не попадают в журнал.
- Длинный вывод команд показывается внутри окна на экране выполнения.
- При маленьком терминале, `TERM=linux` или `AS_UI_ASCII=1` автоматически
  включается ASCII-отрисовка.
- Если Python/curses недоступны, используется `dialog`, затем `--plain`.

Подробности и протокол взаимодействия: [docs/UI.md](docs/UI.md).

## Разметка диска

Всегда создаётся GPT из двух разделов:

| Раздел | Размер | Тип | Использование |
| --- | --- | --- | --- |
| 1 | 1 GiB | EFI System (`ef00`) | FAT32, `/boot` |
| 2 | остаток | Linux (`8300`) | ext4/Btrfs/XFS или LUKS2 |

Для Btrfs внутри корневого раздела создаются подтомы:

- `@` — корень, монтируется с `compress=zstd`;
- `@home` — `/home`;
- `@var_log` — `/var/log`;
- `@snapshots` — `/.snapshots`.

Отдельный swap-раздел не создаётся. Вместо него можно включить zram.

## Безопасность

- Диск перепроверяется непосредственно перед разметкой.
- Отклоняются: диск live-системы, диск текущего корня, диск с любым
  смонтированным разделом, активным swap, активными LUKS/LVM/RAID/mapper
  устройствами и диски меньше 24 GiB.
- Пароли не передаются в аргументах команд и не попадают в журнал:
  `chpasswd` получает их через pipe, `cryptsetup` — через stdin.
- Журнал создаётся с правами `0600`, каталог состояния — `0700`.
- При ошибке или сигнале установщик размонтирует целевую систему и закроет
  LUKS-контейнер, если это безопасно.
- Перед стиранием диска проверяется доступность пакетов и примерный размер
  установки.
- После установки проверяются fstab, наличие ядра, initramfs, systemd-boot,
  пользователя, NetworkManager и загрузочных параметров.

Подробности: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Ограничения

- Только UEFI x86_64 и только systemd-boot. GRUB, rEFInd, Legacy BIOS и MBR не
  поддерживаются.
- Разметка выполняется только «весь диск». Сохранить существующую ОС или
  сделать ручную разметку нельзя.
- Secure Boot: установщик не подписывает загрузчик и не заводит ключи. При
  включённом Secure Boot systemd-boot может не загрузиться, пока ключи не
  добавлены вручную.
- Шифруется только корневой раздел; `/boot` остаётся незашифрованным (иначе
  systemd-boot не сможет прочитать ядро без отдельной настройки).
- Нет swap-раздела и swap-файла; доступен только zram.
- Проприетарные драйверы NVIDIA автоматически не устанавливаются; для
  графических профилей ставится `mesa`.
- Нет автоматического выбора зеркал и нет неинтерактивного файла конфигурации.
  Интеграционный тест в QEMU поэтому ручной.
- Локаль поддерживается только в формате `xx_XX.UTF-8`.
- Нет автоматических снимков Btrfs: подтом `@snapshots` только подготавливается.
- Нет TPM/FIDO2/detached-header для LUKS2.

## Проверка качества

```bash
bash tests/run-tests.sh
```

Тесты безопасны для обычного пользователя: они не размечают диски, не вызывают
`pacstrap`, `sgdisk`, `mkfs`, `cryptsetup` или `bootctl`. Проверяются синтаксис
Bash и Python, ShellCheck, логика безопасности диска, имена разделов,
загрузочные параметры Btrfs/LUKS, fstab, предполётная проверка пакетов (с
поддельным `pacman`), генерация конфигурации, порядок этапов установки и
полноэкранный TUI через настоящий PTY: меню, боковая панель, ввод, маскировка
пароля, подтверждения, экраны сообщений и выполнения команд.

CI (GitHub Actions) запускает тот же набор на каждый push и pull request.

Интеграционный тест в UEFI-виртуальной машине:

```bash
export ARCH_ISO=/path/to/archlinux-*.iso
bash tests/integration/qemu-uefi.sh
```

Подробности: [docs/TESTING.md](docs/TESTING.md).

## Восстановление после сбоя

Если установка прервалась, не запускай её повторно вслепую. Проверь `lsblk`,
размонтируй целевую систему и при необходимости закрой LUKS:

```bash
lsblk -f
umount -R /mnt
cryptsetup close cryptroot
```

Пошаговая инструкция: [docs/RECOVERY.md](docs/RECOVERY.md).

```text
docs/                   архитектура, аудит, тестирование, восстановление
```
